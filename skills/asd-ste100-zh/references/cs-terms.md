# 计算机领域术语表（一词一义）

> 用法：同一概念全文只用「统一用名」这一栏的词。术语表没覆盖的概念，选团队最常用的叫法并保持一致。
> 接口标签、命令、参数名、路径、配置键不在本表范围内，原样保留。

| 统一用名 | 禁混用别名 | 界定 |
|---|---|---|
| 服务 | 服务实例、服务进程（指同一个部署单元时） | 一个独立部署、对外提供功能的进程单元 |
| 接口 | API 端点、endpoint（行文指同一个时二选一） | 两个系统之间约定的调用方式 |
| 函数 | 方法（不带接收者语境时） | 独立的可调用代码单元；挂在对象上的叫方法 |
| 部署 | 发布、上线、发版（指把构建产物放到环境时） | 把构建产物放到目标环境运行 |
| 发布 | 上线（对外宣布可用时） | 向用户宣布并开放新版本 |
| 回滚 | 还原、退回 | 把环境恢复到上一个版本 |
| 配置 | 设置、设定（指修改配置项时） | 修改决定程序行为的参数 |
| 环境 | 环境（不与「机器」「服务器」混用） | 一套独立运行的部署目标（开发/测试/生产） |
| 日志 | 打印、输出（指运行记录时） | 程序运行时写下的记录 |
| 请求 | 调用（指网络请求时） | 客户端发给服务端的一次调用 |
| 响应 | 返回值（指网络响应时） | 服务端对请求的返回 |
| 超时 | 超时（不用「timeout 超时问题」叠用） | 等待超过设定时间后放弃 |
| 重试 | 重连、再次请求（指自动重发时） | 失败后自动再次发起 |
| 熔断 | 熔断降级（与降级连用指两件事时拆开写） | 错误率超阈值后停止请求下游 |
| 降级 | 降级处理 | 关闭部分功能以保住核心功能 |
| 幂等 | 幂等性 | 同一操作执行多次结果不变 |
| 并发 | 并行（未严格区分线程级并行时） | 多个任务在同一时间段内交错执行 |
| 吞吐量 | QPS（写具体数字时用 QPS） | 单位时间内处理的请求数 |
| 延迟 | 耗时、响应时间（指请求用时） | 一次请求从发出到收到响应的时间 |
| 缓存 | 缓冲（指加速读取时） | 暂存一份数据以加速读取 |
| 队列 | 消息队列（首次写全，之后只写队列） | 先进先出的任务/消息暂存结构 |
| 实例 | 节点（指容器或进程副本时） | 服务的一份运行副本 |
| 集群 | 集群环境 | 多个实例组成的整体 |
| 容器 | 镜像（运行中的叫容器，构建产物叫镜像） | 镜像运行起来的隔离进程 |
| 镜像 | 容器文件（指构建产物时） | 容器的只读构建产物 |
| 分支 | branch | 代码线的独立副本 |
| 合并 | merge、合入 | 把一个分支的提交并入另一个分支 |
| 提交 | commit、提交代码 | 把改动记入版本历史的一次动作 |
| 权限 | 授权、权限点（指访问控制时） | 允许某个主体做某件事的规则 |
| 凭证 | 密钥、token（指访问凭据时选一贯穿） | 用于身份验证的信息 |

## 维护说明

- 新概念先查本表；不在表内的概念，确定叫法后加一行。
- 「禁混用别名」指同一语境下不换着叫；不同语境有正当区别时（如「实例」在虚拟机语境），在界定栏写明。

## 补充术语（第二批，含近义辨析）

> 格式说明：「不是」栏列出容易混用的近义词和它们真正的含义——混用的根源是不知道差别，写明差别比禁令有效。

| 统一用名 | 界定 | 不是 |
|---|---|---|
| 删除 | 对象永久去掉，不能恢复 | 移除=从一组里拿出来，对象还在；清空=清空容器，容器还在 |
| 保存 | 存下当前内容，之后可继续改 | 提交=交给他人或系统；发布=对读者可见 |
| 克隆 | 复制整个仓库（含历史） | 拉取=只同步新提交 |
| 构建 | 从源码生成可运行产物 | 编译=单语言源码到目标码（构建包含编译+打包） |
| 联调 | 多个团队/系统接在一起测试 | 测试=单侧自测 |
| 监控 | 持续采集指标 | 告警=指标越界后通知（告警是监控的下游） |
| 网关 | 统一入口，做路由和协议转换 | 代理=转发单个方向的请求；负载均衡=分发流量 |
| 限流 | 限制请求速率 | 配额=长期的用量上限 |
| 主线 | 团队公认的主开发分支 | 主分支=仓库配置里的默认分支（通常一致，冲突时写明确名字） |
| 凭证 | 证明身份的信息（token、密码） | 密钥=加密用的密码学材料；证书=带签名的公钥文件 |
| 配置项 | 一个可配置的键 | 配置文件=配置项所在文件；环境变量=配置项的一种载体 |
| 依赖 | 本项目引用的外部代码 | 包=依赖的分发单位 |
| 回滚 | 恢复到上一个正常版本 | 重启=同一版本重新运行 |
| 灰度 | 先对部分用户开放 | 试运行=内部先用；全量=对所有用户开放 |
| 观测 | 看清系统内部状态（日志、指标、追踪的总称） | 监控=观测里自动采集和告警的部分 |
