# 替换表（大词 → 白话）

> 用法：这是**方向建议**，不是合规清单。左列的写法不是永远禁止——只在它遮住信息时替换。找到更有信息量的写法后，不必逐条对照本表。

## 虚动词（直接用动词）

| 避免写法 | 换成 |
|---|---|
| 对服务进行部署 | 部署服务 |
| 对配置加以修改 | 修改配置 |
| 作出调整 | 调整 |
| 予以处理 | 处理 |
| 完成了对……的升级 | 升级了…… |

## 无数值程度词（写数值或条件）

| 避免写法 | 换成 |
|---|---|
| 大幅提升性能 | 吞吐量从 1000 QPS 提升到 4500 QPS |
| 显著降低延迟 | 平均延迟从 800ms 降到 120ms |
| 尽快处理 | 收到告警后 5 分钟内处理 |
| 大量用户受影响 | 约 12000 名用户受影响 |
| 高可用 | 故障后 30 秒内自动切换 |
| 及时反馈 | 每次失败后立即返回错误码 |

## 报告腔与套话（删除或改具体）

| 避免写法 | 换成 |
|---|---|
| 需要注意的是，…… | （直接写那个事） |
| 在一定程度上影响了性能 | 使 99 分位延迟增加约 200ms |
| 综上所述 | （删除，结论已在正文） |
| 对……进行了优化（没说改了什么） | 写出改了哪个模块、哪个参数 |
| 相关模块 | 写出模块名 |
| 上述问题 | 重复问题名 |

## 黑话（计算机语境下换成具体动作）

| 避免写法 | 换成 |
|---|---|
| 赋能 | 让……能做到（写清能做到什么） |
| 抓手 | 方法、切入点（写清具体是哪个） |
| 闭环 | 走完「发现-修复-验证」全程 |
| 打通 | 让 A 能调用 B 的数据 |
| 沉淀 | 保存成文档 / 写进代码库 |
| 拉齐 | 开会确认口径一致 |
| 落地 | 完成部署并验证 |

## 名词化（还原成动词句）

| 避免写法 | 换成 |
|---|---|
| 完成数据的清洗 | 清洗数据 |
| 实现日志的采集 | 采集日志 |
| 该功能的引入 | 引入该功能后 |

## 强度词分级（规范化为三级）

| 避免写法 | 归入 | 换成 |
|---|---|---|
| 应、应当、务必、一定要 | 要求 | 必须 |
| 应该 | 要求或推荐（先判断） | 必须 / 宜 |
| 建议、最好、尽量 | 推荐 | 宜 |
| 不应、不要、禁止、严禁、切勿 | 禁止 | 不得 |

## 规范动词映射（同类动作各选一个词）

同一类动作全篇只用一个动词，别让读者以为是四件事：

| 动作 | 统一用 | 不再混用 |
|---|---|---|
| 确认某事为真 | 检查 | 验证、确认、校验 |
| 证明代码正确 | 验证 | 检查、确认（跑测试的场景） |
| 修改配置项 | 配置 | 设置、设定 |
| 获取最新代码 | 拉取 | 下载、同步、更新代码 |
| 对外可用 | 发布 | 上线、开放、放出 |
| 回到旧版本 | 回滚 | 还原、退回、撤销发布 |

## 人称与指代

| 避免写法 | 换成 |
|---|---|
| 我们会在 3 个工作日内回复 | 客服团队会在 3 个工作日内回复 |
| 大家都需要遵守 | 所有成员都要遵守（点名群体） |
| 如上所述 / 上述问题 | 重复那个问题或模块的名字 |

## 更多虚词与冗余（中文特有）

| 避免写法 | 换成 |
|---|---|
| 对于……而言 / 在……方面 | 删掉，或写成主语 |
| 由于……的原因 | 因为…… |
| 有助于……的提升 | 能提升…… |
| 做出一个决定 | 决定 |
| 进行数据的一个清洗 | 清洗数据 |
| 旨在 / 致力于 | 删掉，直接说它做什么 |
| 被广泛地应用于 | 广泛用于（描述文才可被动） |


## AI 高频词扩容表（v0.3）

> 收录标准：真实 AI 中文输出中的高频模式（含社区共识：Waza 反 AI 腔清单、STC 不推荐写法、各 STE-skill issue 区）。**技术正当用法保留**：闭环控制、断点调试、全量部署、灰度发布不在此列；每条标注了正当语境的例外。

### 一、过渡与垫场套话（删除，直接写内容）

| 避免写法 | 处理 |
|---|---|
| 值得注意的是 / 需要指出的是 / 值得一提的是 | 删，直接写那件事 |
| 综上所述 / 总而言之 / 总的来说 | 删，结论已在正文 |
| 由此可见 / 不难发现 / 可以看出 | 删，或「说明」+ 直接说结论 |
| 换句话说 / 换言之 | 删（前后本是一件事），或用「即」 |
| 众所周知 / 毋庸置疑 / 不可否认 | 删（拉权威垫场） |
| 究其原因 / 归根结底 / 一言以蔽之 | 删，直接给原因 |
| 从某种意义上 / 在某种意义上 | 删（含糊限定） |
| 随着……的发展 / 在当今……时代 | 删，从事实开场 |
| 这说明 / 这体现了 / 这就是……的魅力 | 删升华，保留事实 |

### 二、虚化动词（换成具体动作）

| 避免写法 | 换成 |
|---|---|
| 赋能 | 让……能做到……（写清能力） |
| 助力 / 护航 | 帮助……做…… |
| 致力于 / 着力 / 深耕 | 直接说在做什么 |
| 发力 / 加码 | 增加……投入（写清对象） |
| 引领 / 抢占 | 写事实：首发 / 市占率 |
| 拥抱变化 | 接受变化并适配（写清做了什么） |
| 夯实 / 筑牢 | 补强、加固（写对象） |
| 沉淀 | 存成文档 / 写进代码库 |
| 打通 / 拉通 | 让 A 能调用 B（写清接口） |
| 拉齐 | 确认口径一致 |
| 落地 | 完成部署并验证 |

### 三、互联网黑话名词（写清具体所指）

| 避免写法 | 换成 |
|---|---|
| 抓手 | 切入点 / 方法 |
| 痛点 | 待解决的问题（写清问题） |
| 打法 / 组合拳 | 做法 / 一组措施（列出） |
| 闭环 | 走完整链（写清哪几步；控制论的闭环控制正当） |
| 赛道 | 领域 / 市场 |
| 心智 | 认知 / 印象（谁的、对什么的） |
| 势能 / 动能 | 潜力 / 动力（多数场合直接删） |
| 护城河 | 竞争壁垒（写清壁垒是什么） |
| 顶层设计 / 底层逻辑 | 整体规划 / 基本原理 |
| 破局 / 破圈 / 出圈 | 写事件本身 |
| 颗粒度 | 写清「细到什么程度」（数据分析领域正当） |
| 维度（这个维度） | 方面 / 角度 |

### 四、空泛形容（删，或换成数字）

| 避免写法 | 处理 |
|---|---|
| 顶级 / 顶尖 / 革命性 / 颠覆性 / 突破性 / 开创性 / 史诗级 / 硬核 / 王炸 | 删，或写出对应事实 |
| 丝滑 / 优雅（体验描述） | 写出流畅的具体表现 |
| 智能化 / 智慧（滥） | 写出「自动」的具体行为 |
| 企业级 / 工业级 / 生产级（无证据） | 写出稳定性数据或认证 |
| 轻量级（无数据） | 写资源占用数字 |
| 高效（无数值） | 写耗时对比 |
| 全面（滥） | 写清覆盖了哪些 |

### 五、空泛副词（删或写数值）

| 避免写法 | 处理 |
|---|---|
| 极其 / 极为 / 十分 / 愈发 / 日益 / 深深地 | 删，或写程度差异的具体数值 |

### 六、人称与立场

| 避免写法 | 换成 |
|---|---|
| 我们 / 咱们 | 具体名称：团队名、系统名 |
| 大家 | 点名群体 |
| 您（技术文档） | 省略主语或写读者角色 |

### 七、结构套式（整段型）

| 避免写法 | 处理 |
|---|---|
| 首先……然后……最后…… | 改编号列表 |
| 一方面……另一方面……（无信息增量） | 按真实关系重排 |
| 不仅……更是…… | 直接说第二层 |
| 无论……还是……都（凑覆盖面） | 删，或写出真实分支 |
| 段末「这说明……」总结句 | 删 |
