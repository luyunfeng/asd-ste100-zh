# 替换表（大词 → 白话）

> 用法：这是**方向建议**，不是合规清单。左列的写法不是永远禁止——只在它遮住信息时替换。找到更有信息量的写法后，不必逐条对照本表。

## 虚动词（直接用动词）

| 避免写法 | 换成 |
|---|---|
| 对服务进行部署 | 部署服务 |
| 对配置加以修改 | 修改配置 |
| 作出调整 | 调整 |
| 予以处理 | 处理 |
| 完成了对……的升级 | 升级了…… |

## 无数值程度词（写数值或条件）

| 避免写法 | 换成 |
|---|---|
| 大幅提升性能 | 吞吐量从 1000 QPS 提升到 4500 QPS |
| 显著降低延迟 | 平均延迟从 800ms 降到 120ms |
| 尽快处理 | 收到告警后 5 分钟内处理 |
| 大量用户受影响 | 约 12000 名用户受影响 |
| 高可用 | 故障后 30 秒内自动切换 |
| 及时反馈 | 每次失败后立即返回错误码 |

## 报告腔与套话（删除或改具体）

| 避免写法 | 换成 |
|---|---|
| 需要注意的是，…… | （直接写那个事） |
| 在一定程度上影响了性能 | 使 99 分位延迟增加约 200ms |
| 综上所述 | （删除，结论已在正文） |
| 对……进行了优化（没说改了什么） | 写出改了哪个模块、哪个参数 |
| 相关模块 | 写出模块名 |
| 上述问题 | 重复问题名 |

## 黑话（计算机语境下换成具体动作）

| 避免写法 | 换成 |
|---|---|
| 赋能 | 让……能做到（写清能做到什么） |
| 抓手 | 方法、切入点（写清具体是哪个） |
| 闭环 | 走完「发现-修复-验证」全程 |
| 打通 | 让 A 能调用 B 的数据 |
| 沉淀 | 保存成文档 / 写进代码库 |
| 拉齐 | 开会确认口径一致 |
| 落地 | 完成部署并验证 |

## 名词化（还原成动词句）

| 避免写法 | 换成 |
|---|---|
| 完成数据的清洗 | 清洗数据 |
| 实现日志的采集 | 采集日志 |
| 该功能的引入 | 引入该功能后 |
