# 替换表（大词 → 白话）

> 用法：这是**方向建议**，不是合规清单。左列的写法不是永远禁止——只在它遮住信息时替换。找到更有信息量的写法后，不必逐条对照本表。

## 虚动词（直接用动词）

| 避免写法 | 换成 |
|---|---|
| 对服务进行部署 | 部署服务 |
| 对配置加以修改 | 修改配置 |
| 作出调整 | 调整 |
| 予以处理 | 处理 |
| 完成了对……的升级 | 升级了…… |

## 无数值程度词（写数值或条件）

| 避免写法 | 换成 |
|---|---|
| 大幅提升性能 | 吞吐量从 1000 QPS 提升到 4500 QPS |
| 显著降低延迟 | 平均延迟从 800ms 降到 120ms |
| 尽快处理 | 收到告警后 5 分钟内处理 |
| 大量用户受影响 | 约 12000 名用户受影响 |
| 高可用 | 故障后 30 秒内自动切换 |
| 及时反馈 | 每次失败后立即返回错误码 |

## 报告腔与套话（删除或改具体）

| 避免写法 | 换成 |
|---|---|
| 需要注意的是，…… | （直接写那个事） |
| 在一定程度上影响了性能 | 使 99 分位延迟增加约 200ms |
| 综上所述 | （删除，结论已在正文） |
| 对……进行了优化（没说改了什么） | 写出改了哪个模块、哪个参数 |
| 相关模块 | 写出模块名 |
| 上述问题 | 重复问题名 |

## 黑话（计算机语境下换成具体动作）

| 避免写法 | 换成 |
|---|---|
| 赋能 | 让……能做到（写清能做到什么） |
| 抓手 | 方法、切入点（写清具体是哪个） |
| 闭环 | 走完「发现-修复-验证」全程 |
| 打通 | 让 A 能调用 B 的数据 |
| 沉淀 | 保存成文档 / 写进代码库 |
| 拉齐 | 开会确认口径一致 |
| 落地 | 完成部署并验证 |

## 名词化（还原成动词句）

| 避免写法 | 换成 |
|---|---|
| 完成数据的清洗 | 清洗数据 |
| 实现日志的采集 | 采集日志 |
| 该功能的引入 | 引入该功能后 |

## 强度词分级（规范化为三级）

| 避免写法 | 归入 | 换成 |
|---|---|---|
| 应、应当、务必、一定要 | 要求 | 必须 |
| 应该 | 要求或推荐（先判断） | 必须 / 宜 |
| 建议、最好、尽量 | 推荐 | 宜 |
| 不应、不要、禁止、严禁、切勿 | 禁止 | 不得 |

## 规范动词映射（同类动作各选一个词）

同一类动作全篇只用一个动词，别让读者以为是四件事：

| 动作 | 统一用 | 不再混用 |
|---|---|---|
| 确认某事为真 | 检查 | 验证、确认、校验 |
| 证明代码正确 | 验证 | 检查、确认（跑测试的场景） |
| 修改配置项 | 配置 | 设置、设定 |
| 获取最新代码 | 拉取 | 下载、同步、更新代码 |
| 对外可用 | 发布 | 上线、开放、放出 |
| 回到旧版本 | 回滚 | 还原、退回、撤销发布 |

## 人称与指代

| 避免写法 | 换成 |
|---|---|
| 我们会在 3 个工作日内回复 | 客服团队会在 3 个工作日内回复 |
| 大家都需要遵守 | 所有成员都要遵守（点名群体） |
| 如上所述 / 上述问题 | 重复那个问题或模块的名字 |

## 更多虚词与冗余（中文特有）

| 避免写法 | 换成 |
|---|---|
| 对于……而言 / 在……方面 | 删掉，或写成主语 |
| 由于……的原因 | 因为…… |
| 有助于……的提升 | 能提升…… |
| 做出一个决定 | 决定 |
| 进行数据的一个清洗 | 清洗数据 |
| 旨在 / 致力于 | 删掉，直接说它做什么 |
| 被广泛地应用于 | 广泛用于（描述文才可被动） |
