# 前后对照示例

> 每组：原文 → 受控中文（标注档位与命中的规则）。R6=句长、R7=的链、R8=分号、R9=指代、R10=虚动词、R11=黑话、R12=套话、R5=程度词、R13=段落过长；T=术语不统一；A=主动语态；C=条件前置。

## 例 1 · 报错信息（严格档）

**原文**

> 数据库连接失败，可能是由于网络波动或者配置不当所导致的，请您检查相关配置后重新进行尝试，如果问题依然存在的话建议及时联系相关运维人员进行处理。

**受控改写**

> 数据库连接失败。两个可能的原因：网络中断、连接配置错误。处理步骤：1. 检查 `database.host` 和 `database.port` 配置。2. 用 `ping database.host` 测试网络。3. 两步都正常仍报错时，联系值班的 SRE（值班表见 oncall.md）。

命中：R6（原句 78 字）、R10（进行尝试）、R5（及时）、R12（相关）、T（配置不当/相关配置 → 指名配置键）、C（条件写清）。

## 例 2 · 工具描述（严格档）

**原文**

> 本工具赋能研发团队，通过强大的自动化能力对部署流程进行深度优化，显著提升交付效率，助力业务快速落地。

**受控改写**

> 本工具自动执行部署：合并请求后自动构建镜像、运行测试、部署到目标环境。构建平均用时 3 分钟。当前只支持 Kubernetes 环境。

命中：R11（赋能、落地）、R10（进行……优化）、R5（显著、快速）、R6，并补上工具描述必需的具体行为与边界。

## 例 3 · 部署步骤（严格档）

**原文**

> 首先你需要修改配置文件中的相关参数，然后进行构建，构建完成之后就可以将其部署到集群当中了，部署完成以后别忘记验证一下服务是否正常，同时还需要更新相关的监控告警配置。

**受控改写**

> 部署步骤：1. 修改 `config.yaml` 中的 `replicas` 参数。2. 运行 `make build` 构建镜像。3. 运行 `kubectl apply -f deploy.yaml` 部署到集群。4. 用 `curl localhost:8080/healthz` 验证服务。5. 更新告警规则 `alerts.yaml`。

命中：一句一动作改有序列表、R10（进行构建/进行部署）、R9（将其）、R12（相关）、T（部署/上线不混用）。

## 例 4 · README 段落（清晰档）

**原文**

> 本项目是一个旨在为广大的开发者提供一个开箱即用的高性能网关解决方案，它采用了业界领先的技术架构，能够极大地简化服务治理的复杂度，助力企业实现数字化转型。

**受控改写**

> 这是一个 HTTP 网关。它转发请求、做鉴权、限流。安装一行命令：`go install github.com/example/gateway@latest`。基准测试见 `bench/README.md`（4000 QPS，单核）。

命中：R11（助力、赋能式表达）、R5（高性能/极大 → 数值）、R12（旨在）、删空壳（业界领先、数字化转型）。

## 例 5 · agent 间指令（严格档）

**原文**

> 你可以先看看那个报错，如果不太对的话就把它修一下，弄好了之后记得跑一下相关的测试，都过了就可以提交了。

**受控改写**

> 任务：修复 `payment-service` 中订单查询的超时错误。步骤：1. 复现错误：`go test ./payment -run TestQueryTimeout`。2. 定位并修复。3. 运行全部测试：`go test ./...`。4. 全部通过后提交，提交信息写明修复的错误编号 PAY-1234。

命中：R9（那个/它）、R5（不太对/记得/一下）、C（条件「都过了」挂到提交上）、一句一动作。


## 例 6 · system prompt 片段（严格档）

**原文**

> 你需要用比较正式的语言回答用户的问题，回答要全面一些，尽量涵盖相关的各个方面，并且可以适当地举一些例子。

**受控改写**

> 回答用户的问题。要求：1. 用正式书面语。2. 覆盖问题的各个方面。3. 在抽象论点处给出例子。

命中：R3（尽量/适当）、R13（相关）、R6；删除缓冲词后要求本身一条不少。

## 例 7 · 运维通报（严格档）

**原文**

> 服务已经被重启了，问题得到了解决，后续会由运维团队进行进一步的排查，并且会对监控进行优化。

**受控改写**

> 服务已重启，故障解除。运维团队接下来会排查根因，并优化监控告警规则。

命中：R16（被动：被重启/得到了解决/由运维团队进行）、R10（进行排查/进行优化）、R17（并且串联）；主动语态 + 计划状态保留（「接下来会」）。
